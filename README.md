# O2《獸源》ORIGIN V2.0 — 獨立 H5 試作版

## 1. 啟動與測試方式
- **單檔版（推薦直接遊玩）**：開啟 `o2_origin_v2.html` 即可於手機 Safari、Android Chrome 或電腦瀏覽器直接遊玩。
- **模組化原始碼版**：若使用本地靜態伺服器（如 `python3 -m http.server`），於本資料夾根目錄啟動後開啟 `index.html`。
- **數值模擬測試**：執行 `python3 sim/o2_balance_sim.py` 可重現 4,300 場戰鬥平衡模擬。

## 2. 操作說明
- **虛擬三鍵 / 鍵盤**：
  - `A`（或鍵盤 `A` / `←`）：切換選單與選項。
  - `B`（或鍵盤 `B` / `Enter`）：確認執行。
  - `C`（或鍵盤 `C` / `Esc`）：**全系統統一安全取消／返回**（可隨時中斷訓練、自動連戰、動畫與選單）。
- **直式手機優先設計**：以 `390×844` 為基準，相容 `320px` 窄螢幕與電腦視窗。

## 3. 尚未完成之正式版功能（保留擴充架構）
- 伺服器權威防作弊驗證（目前試作版使用 `localStorage`，不可用於正式交易或防作弊）。
- 多人跨服排行榜、公會、玩家交易市場、獸園與地圖廢土探索（已在資料結構預留 `ownerId`、UUID 與事件介面）。
- 完整 1,000+ 種正式核准圖鑑素材（目前採用 4 套臨時原創 4×12 精靈圖與程式繪製幼年期素材）。

## 4. 與原 O2 規格之差異與暫定參數標示
- **四維公式與階段上限**：採 V2 暫定遞減收益曲線與百分比減傷＋反傷公式（標示為 `[待驗證]`）。
- **訓練體力消耗**：預設為 `訓練 8 / 對戰 20`，可於「GM 管理面板」一鍵切換為 `1 / 1` 方案即時測試。
- **P2P 連線對戰**：保留 PeerJS 房號連線與同瀏覽器分頁對戰作為連線架構驗證。
